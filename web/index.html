アーキテクチャとローカル推論について

モデルと WASM ランタイムは同一オリジンから読み込み、専用 Web Worker 内で処理します。映像や画像が外部へ送信されることはありません（アップロード 0 bytes）。通常再生では再生を止めずにフレームを取得し、全フレーム解析 (12 FPS) では 12 FPS 間隔で各フレームを順に解析します。カメラ入力には HTTPS または localhost が必要です。

追跡パイプラインは 2D Kalman フィルター＋ReID による車両・プレート追跡、Pass-2 マウント探索 / Smart-Zoom 高解像度切り出し、および 60 FPS 描画スムージングを実行します。文字認識は JP7029732B2 準拠の終端読み出し（COLLECTING 中は 0 回、トラック確定・退出時にのみ 1 回）に厳密に限定されています。サンプル映像は合成動画であり、遠距離・低解像度では棄却（UNREADABLE）される場合があります。
