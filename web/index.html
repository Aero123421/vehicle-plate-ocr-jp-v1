デモについて

モデルと WASM は同じサイトから読み込み、専用 Worker で処理します。動画は 12 FPS で解析します。カメラの利用には HTTPS または localhost が必要です。

サンプルは合成映像です。ブラウザー版の追跡は簡易 IoU 方式で、Python 版の PMBM 追跡・Smart-Zoom と異なります。遠距離・低解像度では棄却や「?」表示が増えます。公開ベンチマークは Python 版の記録です。
